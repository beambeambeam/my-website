# Tool logos

C# and Playwright use SVGs from [Devicon](https://github.com/devicons/devicon). The files use the [MIT license](./LICENSE).

- [C# source](https://github.com/devicons/devicon/blob/master/icons/csharp/csharp-plain.svg)
- [Playwright source](https://github.com/devicons/devicon/blob/master/icons/playwright/playwright-plain.svg)

The card uses these SVGs as alpha masks. This preserves transparent areas during the color reveal. The other mono logos come from the installed `simple-icons` package.

## Full-color logos

The SVGs in `color/` come from the [SVG Logos](https://github.com/gilbarbara/logos) set by Gil Barbara, through [Iconify](https://icon-sets.iconify.design/logos/). The set uses the [CC0 1.0 license](https://github.com/gilbarbara/logos/blob/master/LICENSE.txt).

Tools whose logo is mono by design (Next.js, shadcn/ui, Expo, TanStack, Drizzle, Vitest) have no full-color SVG. The card shows them in their brand color.
